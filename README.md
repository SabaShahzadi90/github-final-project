# Simple Interest Calculator

## Introduction
This repository contains a Simple Interest Calculator project created as part of the GitHub final project assignment. 
The calculator computes the Simple Interest based on Principal, Rate, and Time.

## Formula
Simple Interest is calculated using the formula:
SI=(P_R_T)/100
Where:
- **P** = Principal Amount
- **R** = Rate of Interest (in %)
- **T** = Time (in years)
